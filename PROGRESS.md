# Состояние проекта

Обновлено: 15 ноября 2026. Текущая версия: **2.0.2**. Основная линия разработки: `rewrite/personal-archive-v2`.

## Готово

- [x] Чистая реализация личного бота без зависимости от старой базы.
- [x] Зашифрованные inbox, сообщения, версии, поиск и файлы.
- [x] Сохранение контекста ответов, удалений и неизвестных полей API с исключением правок владельца.
- [x] Автоматическая независимая доставка всех основных вложений при удалении.
- [x] Постоянные очереди, повторные попытки и защита от устаревших workers.
- [x] Поиск, закладки, настройки уведомлений и тихие часы.
- [x] Компактные HTML-карточки, «Было / Стало», обновление меню на месте.
- [x] Выдача сохранённых вложений как native media с безопасным document fallback.
- [x] Зашифрованные backup, восстановление и экспорт JSONL/HTML с файлами.
- [x] Docker, CLI, lock-файл зависимостей и GitHub Actions.

## Проверено

На коде 2.0.2 прошли 132 теста на macOS и Linux AMD64, Ruff и mypy. Проверены аварийная остановка, ошибка записи, очереди, стирание, доступ владельца, шифрование и HTTP-интеграция с двойником Telegram. После развёртывания подтверждались успешный опрос Telegram и health check. Это проверка запуска, а не всех реальных типов сообщений.

Подробности: [VERIFICATION.md](docs/VERIFICATION.md).

## Открыто

- [ ] Проверка обновлённых карточек владельцем в реальном клиенте Telegram.
- [ ] Длительный прогон и нагрузочная проверка на большом архиве.
- [ ] Проверка фактической доставки одноразовых медиа и больших файлов через выбранный профиль Bot API.
- [ ] Уведомления о нехватке диска и улучшенная диагностика архивирования.
- [ ] Автоматическая очистка зашифрованных временных остатков после жёсткого завершения процесса.

Для постоянного использования нужен запас диска и резервная копия ключа вне сервера. Метаданные недоступного файла не считаются сохранёнными байтами.
