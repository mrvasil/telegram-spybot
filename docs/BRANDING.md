# Графика проекта

Название: **Spybot**. Краткое описание: «Личный архив Telegram».

Знак объединяет две карточки сообщений и отметку сохранения. Он используется в документации и подходит для аватара бота. Это собственная графика проекта, не официальный знак Telegram.

| Файл | Назначение |
| --- | --- |
| [icon.svg](../assets/icon.svg) | Векторная иконка 512 × 512 |
| [icon.png](../assets/icon.png) | Готовый PNG для аватара 512 × 512 |
| [banner.svg](../assets/banner.svg) | Исходник обложки 1200 × 360 |
| [banner.png](../assets/banner.png) | Обложка README с фиксированным отображением шрифтов |
