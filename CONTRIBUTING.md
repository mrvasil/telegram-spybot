# Разработка

Перед изменениями прочитайте [AGENTS.md](AGENTS.md). Для работы нужны Python 3.13 и uv.

```bash
uv sync --frozen
uv run pytest -q
uv run ruff check src tests
uv run ruff format --check src tests
uv run mypy src/spybot
```

Тесты работают на временных базах, файлах и локальном HTTP-сервере. Реальный бот и Telegram-токен для них не нужны.

## Подготовка изменения

1. Опишите конкретное поведение и сценарий, который его меняет.
2. Для ошибки сохранения, доступа или доставки добавьте воспроизводящий её тест.
3. Вносите небольшие изменения, сохраняя свойства из AGENTS.md.
4. Обновите руководство или CHANGELOG.md, если изменилось поведение.
5. Проверьте diff на секреты и личные данные перед отправкой.

В описании PR укажите проблему, результат и выполненные проверки. Отдельно перечислите непроверенные реальные интеграции. Не заявляйте успешное развёртывание по результату локального теста.

## Зависимости

Меняйте `pyproject.toml` вместе с `uv.lock`. Установка в CI и Docker использует `uv sync --frozen`. Изменения схемы, формата шифрования, порядка подтверждения updates и повторных отправок требуют отдельного внимания при ревью.
